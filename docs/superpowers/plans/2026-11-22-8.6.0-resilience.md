# 8.6.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Harden the static app before adding more content: resilient external game images, a shared hot-link player helper, a single source of truth for the version, leaner assets, and CI/check tooling that scales.

**Architecture:** Keep the project's plain-script, no-build style. Add small global helpers (`js/hotlink-player.js`, `js/version.js`), consolidate check metadata in JSON, add browser smoke checks via the existing MCP, and use check scripts under `docs/superpowers/` to guard each invariant. Game card images already fall back to `../images/game.svg` on error; keep that exact fallback (the user's requested behaviour) and add SW caching plus a CI URL check rather than restoring local icons.

**Tech Stack:** Vanilla JS, Service Worker, GitHub Actions, Node check scripts, `cwebp`/Pillow for image conversion, chrome-devtools MCP for browser smoke checks.

- [ ] **Step 1: Cache remote game images in the service worker**

Add a cache-first branch before the generic network-first handler in `sw.js`:

```js
const GAME_IMAGE_CACHE = 'ewtv-game-images-v1';
const GAME_IMAGE_HOSTS = ['raw.githubusercontent.com', 'cdn.simpleicons.org'];
// in fetch handler, after the COOP/COEP navigation branch:
const reqUrl = new URL(event.request.url);
if (event.request.destination === 'image' && GAME_IMAGE_HOSTS.includes(reqUrl.hostname)) {
  event.respondWith(
    caches.open(GAME_IMAGE_CACHE).then(async (cache) => {
      const cached = await cache.match(event.request);
      if (cached) return cached;
      try {
        const response = await fetch(event.request);
        if (response.ok) cache.put(event.request, response.clone());
        return response;
      } catch (e) {
        return new Response('', { status: 504, statusText: 'Offline image' });
      }
    })
  );
  return;
}
```

The existing `onerror="this.src='../images/game.svg'"` in `js/togame.js:1233` already implements the requested Games-icon fallback; do not change it.

- [ ] **Step 2: Add a CI check for all remote image URLs**

Create `docs/superpowers/check-remote-images.js` that extracts `image: 'https://…'` from `js/togame.js`, fetches each unique URL with `fetch` (Node 20), treats non-2xx as failure, and prints `checked N unique remote images | ALL OK` or exits 1 listing failures. Add it to `checks.yml` after "Game catalogue".

### Task 2: Shared hot-link player helper

**Files:**

- Modify: matching `routes/*.html` files (add script tag)
- Create: `docs/superpowers/check-hotlink-player.js`

- [ ] **Step 1: Implement the helper**

`js/hotlink-player.js` exposes `window.HotlinkPlayer`:
- `ensureIsolated(namespace, consoleTag, swPath)` – registers the SW, reloads once if `window.crossOriginIsolated` is false using a namespaced sessionStorage key.
- `watchIframe(iframe, link, t, opts)` – sets `link.href`/`link.textContent` from the current URL or a base, clears the slow timer on iframe `load`, shows a toast after 15s.
- `showToast(msg)` – creates/reuses a `#hotlink-toast` element with the project's toast styling.

No ES modules; plain global, matching the codebase style.

- [ ] **Step 2: Migrate the five isolated pages**

Replace the inline `crossOriginIsolated` IIFEs in `js/tomac.js`, `js/ton64recomp.js`, `js/tops2.js`, `js/torustpal.js`, `js/tovita.js` with `HotlinkPlayer.ensureIsolated(namespace, tag, '../sw.js')`.

- [ ] **Step 3: Migrate slow-load handling in representative pages**

For `js/towebgame.js`, `js/todiablo.js`, `js/toz2rs.js` (and any others with `slowTimer`), replace the local slowTimer/toast/link setup with `HotlinkPlayer.watchIframe(...)`, preserving all 8-language strings. Add `<script src="../js/hotlink-player.js"></script>` before the page script in matching HTML files.

- [ ] **Step 4: Guard the migration**

Create `docs/superpowers/check-hotlink-player.js` asserting: helper exists and defines both methods; every page referencing `crossOriginIsolated` calls `ensureIsolated`; every page defining `slowTimer` calls `watchIframe`; every HTML whose JS uses the helper loads `../js/hotlink-player.js`. Add to `checks.yml`.
