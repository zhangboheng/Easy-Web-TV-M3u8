Boot an Android-x86 Image

Select an Android-x86 .iso or .img and boot Android in a local browser x86 VM. Bring your own lawful image; this project bundles no Android system, GApps, or apps.

The image stays on your device and is never uploaded. Images are large: desktop Chrome/Edge is recommended and the first boot can take a while.

Enter a direct URL to an Android-x86 .iso / .img (the host must allow cross-origin access)

Instructions

Controls

  • Click the screen for keyboard focus; after Android-x86 boots, use the mouse to tap the UI and press Esc to leave fullscreen.
  • Android x86 6/7 or smaller images are recommended; try another image if RAM is insufficient or boot fails.

About

  • This page uses v86 (BSD-2-Clause) to emulate an x86 PC in the browser. It distributes no Android system image, GApps, or proprietary software; obtain images from the Android-x86 project or another lawful source.
