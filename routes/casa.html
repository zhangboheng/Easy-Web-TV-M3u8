Casa de Gemas Hidden Gems

Find seasonal hidden gems in a watercolor Spanish house: shake branches, water the garden, rake leaves and listen to Oli the owl tell the story from spring to winter. The game is hot-linked from its official static build.

This host bundles no game code or assets - visuals are drawn with Canvas and music/sound are generated with Web Audio. Use “Open in a new tab” to use name and season URL parameters.

Instructions

Controls

  • Drag with the mouse to look around the courtyard, then click or drag objects to shake trees, pour water and rake leaves. Find every gem in the current season to reveal the final snowy-day surprise.
  • The desktop version is designed for mouse input; the author also provides a mobile touch version. Sound starts muted - click the speaker icon in the page to enable it.

About

  • Casa de Gemas is an interactive watercolor garden built entirely through conversation with Claude Opus 5.5, using Canvas 2D and Web Audio with no external image or audio files. By deepujain, MIT licensed.
