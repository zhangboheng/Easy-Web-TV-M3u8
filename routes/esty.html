Atari ST Emulator

Run the 68000-era Atari ST 520/1040 in your browser, embedded by hotlink to the official EstyJS web app. EstyJS 2.0 uses open-source EmuTOS and provides floppy loading, mouse synchronisation and fullscreen mode.

This host bundles no ROMs or software - EstyJS and EmuTOS are served by the official site, and .st/.sts floppy images are loaded in the emulator own UI. Use the ‘Open in a new tab’ link for the full standalone experience.

Instructions

Controls

  • Click floppy drive A or B to load a .st/.sts image; click the embedded screen for keyboard focus, and use the middle mouse button to realign the pointer if needed.
  • Cursor keys and Ctrl emulate joystick 1, and real USB gamepads are supported; use the EstyJS toolbar for pause, sound, reset and fullscreen.

About

  • The Atari ST is a 16-bit home/professional computer launched in 1985 with a Motorola 68000 and built-in MIDI. Emulation by kaiec/EstyJS (GPL-2.0-or-later), using open-source EmuTOS by default.
