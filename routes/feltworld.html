Felt World Open World

Explore a procedural 3D open world in your browser: drive, walk, fly, dive and explore beneath the sea. The game is embedded by hotlink from the official Felt World static build.

This host bundles no game code, textures or audio - Felt World and its three.js dependencies are loaded from the official site. Use the “Open in a new tab” link for the full standalone experience.

Instructions

Controls

  • Click inside the game area first so it receives keyboard input. Follow the in-game prompts to switch between driving, walking, flying, diving and submarine modes; touch controls are also supported.
  • Use the game own UI for pause, reset and fullscreen; press Esc or use the Reset button above to come back here.

About

  • Felt World is a single-file 3D open-world experiment built with three.js. Textures are generated with canvas and sound is synthesized with Web Audio. By az9713, MIT licensed.
