J2ME Mobile Games

Run Java ME (J2ME) phone games in your browser with J2meJS (GPL-2.0, embedded by hotlink to the official demo). The official demo hosts a library of classic midlets - open it to pick a game, or load your own .jar below.

Commercial midlets hosted elsewhere are not hotlinked here - run jars you own or that are freely distributed.

Load a Jar from URL

Enter the direct URL of a .jar (Java ME midlet) file

Tip: the file server must allow cross-origin access (CORS). GitHub raw and release links work.

Run a Local Jar

Select your own Java ME .jar (midlet) file

The jar stays in your browser - nothing is uploaded to any server. Run only software you own or that is freely distributed.

Instructions

Controls

  • Number keys / arrows map to the phone keypad; 5 = action, * and # are supported
  • A virtual keypad appears inside the emulator for touch devices

About

  • J2ME: Java Platform, Micro Edition - the platform of 2000s feature-phone games (MIDP 2.0). Emulation via J2meJS by Rosabis (GPL-2.0), embedded by hotlink.
