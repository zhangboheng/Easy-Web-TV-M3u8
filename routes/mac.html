Classic Macintosh Emulator

Run a classic Macintosh in your browser with Infinite Mac (embedded by hotlink to the official web app). System 7.1 boots by default, with the Infinite HD bonus software disk mounted.

No ROMs and no software are bundled - the emulator runs System 7.1 from the Infinite Mac project inside your browser; nothing is uploaded. Your disks and preferences persist in your browser's storage, and you can switch to other classic Mac OS versions from the emulator's own menu; the “Open in a new tab” link gives you the full standalone experience.

Instructions

Controls

  • The Mac desktop is controlled with your mouse and keyboard inside the embedded screen; use the emulator's own menu to pause, reset or change the emulated machine
  • System 7.1 boots by default with the Infinite HD software disk mounted; open the emulator's disk menu to mount your own disk images or switch to another classic Mac OS release

About

  • Classic Macintosh: Apple's 1984-2001 personal computers. Emulated by Infinite Mac (Apache 2.0), embedded by hotlink to the official web app. This host page runs cross-origin isolated, so SharedArrayBuffer stays available for full-speed emulation.
