N64 Static Recomp

Run n64hub static recompilations of Nintendo 64 games in your browser. Game code is recompiled by N64Recomp with RT64 graphics and runs via WASM/WebGPU, embedded by hotlink from each project official page. Nothing is bundled here.

Bring your own lawfully obtained ROM and select the matching game version inside n64hub. Pick the ROM inside the n64hub page on first launch; nothing is uploaded to this app. Requires a recent desktop Chrome/Edge with WebGPU and cross-origin isolation. Independent, unofficial projects not endorsed by Nintendo.

Instructions

Controls

  • Use a keyboard or gamepad; click inside the game area first so it receives input, and press Esc to release the keyboard
  • On first launch choose your own USA ROM inside the n64hub page; ROMs, settings and saves may not survive closing or reloading the embedded page

About

  • N64Recomp (GPL-3.0) statically recompiles N64 game code; RT64 provides rendering and the browser build uses Emscripten/WASM with WebGPU. This page hot-links n64hub builds, is not affiliated with Nintendo and ships no ROMs.
