NOVA LANCER Rail Shooter

Play an original 3D rail shooter in your browser: fly through coastlines, canyons and a night city using charge lock-on, smart bombs and rolls. The game is hot-linked from its official static build.

This host bundles no game code or assets - terrain, models, music and sound are generated by the official page. Use “Open in a new tab” for the full experience.

Instructions

Controls

  • Click the game area first for keyboard focus. Move with WASD/arrows, fire with J/Space, hold to charge lock-on, press K for a Smart Bomb and Q/E to roll.
  • Mouse, gamepad and mobile touch controls are supported; pause, settings and graphics quality live in the game menu, and Esc pauses.

About

  • NOVA LANCER is an original Star Fox-inspired 3D rail shooter made with Claude Code and Claude Opus 5.5. three.js and all procedural assets are packaged into a single page. By たぬ, MIT licensed.
