Red Alert 2 Games

Run Red Alert 2 and Yuri's Revenge directly in your browser with RA2 VM (v86 + Win32/DirectX compatibility layer, embedded by hotlink to the official site). Supports skirmish, saves and multiplayer.

No games are bundled - bring your own copies of Red Alert 2 or Yuri's Revenge and import them in the page to play. Not endorsed by EA.

Instructions

Controls

  • Build, select units and fight with mouse/touch, or use keyboard shortcuts
  • On first launch, import your own Red Alert 2 or Yuri's Revenge game resources inside the emulator, then pick a version to start a skirmish

About

  • Red Alert 2: the 2000 classic PC RTS from Westwood/EA. The web version is provided by RA2 VM (v86 engine, GPL-3.0), embedded by hotlink; currently Alpha.
