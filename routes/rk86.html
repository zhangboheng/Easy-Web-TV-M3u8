Radio-86RK Emulator

Run the 1986 Soviet home computer Radio-86RK in your browser, embedded by hotlink to the official rk86.ru web app. The site ships a large catalog of demo programs, and you can load your own program files from the emulator UI.

This host bundles no ROMs or software - the emulator and its demo catalog are served by rk86.ru, and program files are loaded in the emulator own UI. Use the ‘Open in a new tab’ link for the full standalone experience.

Instructions

Controls

  • Click the embedded screen for keyboard focus, then press CMD/CTRL-K for command help; l selects a file, o opens the catalog and g runs a program.
  • Formats include .rk, .rkr, .gam, .pki and .bin; use the emulator own shortcuts for pause, reset, save state and fullscreen.

About

  • Radio-86RK is a Soviet 8-bit home computer from 1986 based on the Intel 8080 / КР580ВМ80A. Emulation by begoon/rk86-js (MIT), embedded by hotlink to the official rk86.ru site.
