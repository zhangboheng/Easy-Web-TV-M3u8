Instructions

Controls

  • Click the screen to give it keyboard focus; the guest OS handles input like a real PC
  • Double-click the screen to lock the mouse, press Esc or double-click again to release
  • If the screen stalls at "Press any key" or a DOS prompt, click it and press Enter; for the Windows 3.0 preset type WIN/3

Fullscreen: use the toolbar buttons above the screen

  • Press ESC to exit fullscreen
