PS Vita Emulator

Run PlayStation Vita games in your browser with vitaslop (MIT, embedded by hotlink to the official web app). The Vita's ARM code is translated to WebAssembly at runtime and the GPU command stream is replayed as WebGPU.

No games are bundled - add your own legally dumped packages (.pkg + work.bin, a dumped folder, or a zip) inside the emulator library; nothing is uploaded. The embedded player uses temporary isolated storage, so games and saves do not survive closing or reloading; use the “Open in a new tab” link for persistent local storage. Early days: many commercial games boot and play, many do not; homebrew works.

Controls

  • Games are controlled with keyboard and mouse once the emulator has focus; the touch pad maps to mouse/touch
  • Open Add games inside the emulator to import your own packages first; games and saves persist in your browser

About

  • PS Vita: Sony's handheld (2011-2019). Emulation via vitaslop (MIT), embedded by hotlink. Requires WebGPU, JSPI, SharedArrayBuffer and OPFS - i.e. a recent desktop Chrome/Edge (mobile Safari/Firefox not supported).
