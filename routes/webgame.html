Web Game

Play open-source web games in your browser, embedded by hotlink from each project's official demo site. Nothing is bundled - every game runs directly from its author's hosted build.

All works are open source or free-licensed (MIT / GPL / BSD / Apache / MPL / CC BY-NC). The list of games and their licenses is in the app README. Not affiliated with any game author.

Instructions

Controls

  • Most games use the arrow keys plus Space/Enter; some also support touch
  • Click inside the game area first so it receives keyboard input; press Esc or use the Reset button to come back here

About

  • A collection of classic open-source web games: 2048, Pac-Man, T-Rex Runner, Space Invaders, SkiFree, Flappy Bird, HexGL, Astray, Q1K3, Underrun, Papertrails, Mist Gate (雾锁山门), plus the text games A Dark Room, Life Restart (人生重开模拟器), Candy Box 2, Antimatter Dimensions and Xiuxian Cultivation (文字修仙) - all hot-linked from their official demo sites.
