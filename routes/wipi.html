WIPI Mobile Games

Run Korean WIPI (SKVM/J2ME) feature-phone games in your browser with WIE (MIT, embedded by hotlink to the official web app). WIPI was the standard mobile platform in South Korea from 2001 to 2009.

No games are bundled - load your own .jar / .bin files inside the emulator. Only run software you own or that is freely distributed.

Instructions

Controls

  • Number keys / arrows map to the phone keypad; use the on-screen buttons with mouse/touch
  • If a game does not run, try changing the engine type (SKVM/WIPI/J2ME) or compatibility flags in the emulator settings

About

  • WIPI: Wireless Internet Platform for Interoperability - the Korean mobile standard (2001-2009) that ran SKVM/J2ME apps. Emulation via WIE by dlunch (MIT), embedded by hotlink.
